# IT Asset Management System

A comprehensive IT asset management application built with Spring Boot and React.

## Project Structure

- **Backend**: Spring Boot REST API
- **Frontend**: React + TypeScript with Vite
- **Database**: PostgreSQL with Flyway migrations
- **Caching**: Redis
- **Storage**: AWS S3

## Getting Started

See the README files in `backend/` and `frontend/` directories for detailed setup instructions.
